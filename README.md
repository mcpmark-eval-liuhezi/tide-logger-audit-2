# tide-logger-audit-2

Handover audit trail for the tide-logger hackathon project.

## What happened here

The default branch on `main` carries three commits, in order:

1. Add the tide log schema (`tide-log-schema.md`) — the data model for one tide reading.
2. Add analysis notes (`analysis-notes.md`) — working notes on the analysis carried out in the project notebook.
3. Add the CI workflow (`.github/workflows/audit.yml`) — runs on pushes to `main` and uploads a small text artifact named `audit-report`.

## Release readiness checklist

The handover checklist is tracked in this repository as issue #1. Walk through it before the handover so the receiving group can verify the audit trail end to end.
